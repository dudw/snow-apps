# 2026-10-27

## snow_shot：文本识别/翻译改为独立结果窗口

需求：识别结果不再叠在选区上，改为独立窗口 —— 左侧原图预览，右侧识别文本 + 译文（参考设计图）。

### 新增文件
- `include/snow_shot/presentation/screenshottextresultwindow.h`
- `src/presentation/ocr/screenshottextresultwindow.cpp`
- `tests/screenshot_text_result_window_tests.cpp`

窗口基于 `adqt::widgets::AdModal`（Window 模式 / 无 footer / Esc 关闭 / `setWindowAlwaysOnTop(true)`，
因为 overlay 常在置顶层）。内容为 `QSplitter`：左侧 `ScreenshotTextResultPreviewView`（QGraphicsView
子类，滚轮 0.05–16 缩放、ScrollHandDrag 平移、双击自适应、`m_fitting` 防递归），右侧 `QScrollArea`
内依次是语言行（源/目标 `AdSelect` + Translate）、动作行（Recognize Again / More Settings /
排版 `AdSelect`）、分隔线、识别文本区、翻译区（各带 Copy/Save 图标按钮与状态 QLabel）。

### 关键设计
- 窗口只做展示，用户意图通过信号上抛（recognizeRequested / translateRequested / typesettingChanged /
  translationSettingsRequested / save*Requested / copyImageRequested / closed），识别状态仍在 session。
- `ScreenshotOcrController` 构造时 `m_session->setExternalTextResultHost(true)`，session 不再把
  `AdTextEdit` 塞进 overlay，避免双重编辑器；`textResultChanged(true)` 后 `presentTextResultWindow()`
  （自动动作是 copy_text_and_end 类则不弹，避免闪窗）；`textDraftChanged` 按 `session->translating()`
  区分推译文还是识别文本（流式翻译直接刷新右侧译文区）。
- session 新增 `reRecognizeText()`（清缓存/取消翻译 job/清 presentation 后重新识别）、
  `translationSourceLanguage()/translationTargetLanguage()/applyTextSourceLanguage()`。
- 关闭窗口 = 退出识别：`closed` → `QTimer::singleShot(0)` + activationId 校验后 `deactivate()`。
- 排版下拉复用 `ocrFormattingOptions()`；改排版走 `session->applyTextFormatting()`，
  由于 external host 下 `beginTextEditing()` 仍会建 editing session（只是不 showTextEditor），排版能真实生效。
- `setTranslationAvailable(bool)`：mini 版（`edition::textTranslation == false`）隐藏语言行与翻译区，
  避免留下空控件和死按钮。
